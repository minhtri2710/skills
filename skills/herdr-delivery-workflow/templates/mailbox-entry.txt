scripts/mailbox.py --file ~/.herdr/projects/<project-slug>/supervisor-mailbox.md --append --from <lead> --to supervisor --repo <checkout> --event "<one line naming the gate id or PR>" [--attention <event-kind>]
Only for what no ledger row holds, add --stdin with a quoted heredoc (the body is data):
  ... --stdin <<'EOF'
<a few lines>
EOF

The script writes this exact header, then any body:
## <lead> -> supervisor | <UTC YYYY-MM-DDTHH:MM:SSZ at write time> | ATTENTION <project-slug> <event-kind>: <one line> | HEAD <full 40-hex HEAD of --repo>
(without --attention the header is an answer header and omits the ATTENTION segment; <project-slug> is the mailbox's directory name)
