push (the Lead's feature-branch push; refused when the range touches a path outside --boundary, repeated once per path, or the head is not the checked-out branch's HEAD commit):
scripts/gate_row.py --ledger ~/.agent-delivery/projects/<project-slug>/gates.md --kind push --status recorded:push --record timely --push [--push-seconds <N>] --push-base <remote tip the stack lands on> --boundary <declared path of the delivery> --words seat --note "<why this push>" --quote "<the push command>"
# --push-seconds <N> (an integer, 1 to 1800; default 120) bounds the push, its pre-push hook included (lead.md, "Review and push coverage").

local-ops:
scripts/gate_row.py --ledger ~/.agent-delivery/projects/<project-slug>/gates.md --kind local-ops --status recorded:local-ops --record timely --op "<one named command>" --after <branch>@<exact head the merge landed> --words seat --note "<why this local op ran>" --quote "<the named command>"

standing-delegation (offer these prefilled values in one question; the Lead is the default delegate, as who=supervisor adds a relay hop to every merge):
scripts/gate_row.py --ledger ~/.agent-delivery/projects/<project-slug>/gates.md --kind standing-delegation --status recorded:standing-delegation --record timely --who lead-<project-slug> --scope "<delegated scope>" --conditions "independent review PASS on the exact SHA; CI green on that SHA" --expiry "<ISO-8601 UTC time or named event>" --words human --note "<note>" --brief "<Agent brief: the grant restated>" --quote ""
# --brief is required, with an empty quote, on every words=human or words=selected row and refused on any other (lead.md, "Attribution").
# CI green holds where the project's ci trigger runs: under pr only on a PR, so work reaches the target line by PR merge, never a direct push;
# under push on the pushed head's run; with no ci the clause is dropped.

correction (void one earlier review-pass row):
scripts/gate_row.py --ledger ~/.agent-delivery/projects/<project-slug>/gates.md --kind correction --status recorded:correction --void <id> --words seat --note "<why the verdict does not stand>" --quote "<correction source>"

Human-gate mailbox check:
scripts/gate_row.py --ledger ~/.agent-delivery/projects/<project-slug>/gates.md --check --mailbox ~/.agent-delivery/projects/<project-slug>/supervisor-mailbox.md
# For an open row of a kind marked human_gate in gate_row.py's KINDS table, the mailbox must contain
# an entry to supervisor that `scripts/mailbox.py --append --attention` wrote before its wake (templates/mailbox-entry.txt),
# and its attention text must name the row's gate id or exact full head SHA as a complete token.
# The header's HEAD field alone does not match. Without --mailbox, --check is unchanged.
